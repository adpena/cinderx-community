# CinderX vs Cinder

The upstream README distinguishes CinderX from Cinder:

- Cinder is Meta's Python runtime implementation.
- CinderX is a package built to bring performance features to stock CPython.

Source: [facebookincubator/cinderx README](https://github.com/facebookincubator/cinderx)

The README also notes that additional CinderX-only features may not remain compatible with stock CPython.
