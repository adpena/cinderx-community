## Confirmed By Code/Test

- Upstream contributor guidance recommends `cinderx.jit.force_compile` to isolate failures and `PYTHONJITDUMPASM=1` for assembly+HIR dumps.
  Source: [cinderx/AGENTS.md#L95](https://github.com/facebookincubator/cinderx/blob/31bca9f3156b78cca3c6b36000c42c48f5ddf037/cinderx/AGENTS.md#L95)
- `jit_log_stats_parser.py` is a dedicated log parser for `-X jit-dump-hir-stats`.
  Source: [cinderx/TestScripts/jit_log_stats_parser.py#L1](https://github.com/facebookincubator/cinderx/blob/31bca9f3156b78cca3c6b36000c42c48f5ddf037/cinderx/TestScripts/jit_log_stats_parser.py#L1)
- The parser explicitly matches compile start/finish and per-function JSON stats lines.
  Source: [cinderx/TestScripts/jit_log_stats_parser.py#L74](https://github.com/facebookincubator/cinderx/blob/31bca9f3156b78cca3c6b36000c42c48f5ddf037/cinderx/TestScripts/jit_log_stats_parser.py#L74)
- The same script exposes `analyze`, `compare`, and diff-fail workflows via CLI subcommands.
  Source: [cinderx/TestScripts/jit_log_stats_parser.py#L634](https://github.com/facebookincubator/cinderx/blob/31bca9f3156b78cca3c6b36000c42c48f5ddf037/cinderx/TestScripts/jit_log_stats_parser.py#L634)
- Perf integration logic copies JIT entries to perf maps and checks evaluator/trampoline state.
  Source: [cinderx/Jit/perf_jitdump.cpp#L346](https://github.com/facebookincubator/cinderx/blob/31bca9f3156b78cca3c6b36000c42c48f5ddf037/cinderx/Jit/perf_jitdump.cpp#L346)

## Inferred / Hypothesis

- Inference: practical observability is designed as layered signals (runtime env flags, structured logs, and perf symbol materialization) rather than a single canonical debug API.

## Unknown Yet

- Recommended minimum logging profile for low-overhead production diagnosis is not yet documented as a source-backed preset.
