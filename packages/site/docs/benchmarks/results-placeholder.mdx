# Results dashboard

This page renders benchmark summaries published under `data/summary/*.json` and mirrored to
`packages/site/static/data/summary/*.json`.

## Publication model

- One machine-readable summary artifact per run (JSON)
- Raw runtime artifacts linked from the summary payload
- Commit SHAs and machine metadata included in every run
- Speedup values are always relative to the baseline runtime in the same run
- CinderX-first policy is enforceable via `--require-cinderx-baseline` for comparison runs
- Canonical publishable CI artifacts are produced by the pinned CinderX lane only (`ubuntu-22.04` + pinned CPython)
- Canonical published headline data is full `pyperformance` (non-`ci_mode`) with CinderX baseline policy enabled
- The `ubuntu-latest` lane is diagnostics-only and is not used as a headline publish source
- Includes a dedicated CinderX-first headline preset (`CinderX Headline View`) with a per-benchmark delta table
- Includes per-benchmark statistical fields (`p_value`, optional RSS, optional compile time) in dashboard tables
- The CinderX headline preset is only active for summaries that actually include a CinderX baseline runtime
- Runtime speedup charts are intentionally hidden for non-CinderX-baselined summaries to avoid CPython-framed headline comparisons
- Includes a `Published runs` table (date, suite, run id, machine, baseline, policy, mode) for quick provenance checks
- Publishable summary history is persisted to the `bench-results` branch for trend ingestion (`history/index.json`)
