# Results dashboard

This page renders benchmark summaries published under `data/summary/*.json` and mirrored to
`packages/site/static/data/summary/*.json`.

## Publication model

- Each run publishes one JSON summary with links to raw runtime artifacts.
- Every summary includes provenance (`run_id`, commit SHA, machine, and suite metadata).
- Dashboard cards expose benchmark counts, runtime coverage, publishability mode, bootstrap flags,
  and CinderX feature activation details (JIT mode/threshold + static-loader state).
- Machine profile, toolchain provenance, and guardrail checks are shown inline for each selected run.
- Speedups are always calculated against the baseline from the same run.
- Headline publishing is CinderX-first: only pinned CinderX-baselined `pyperformance` runs are canonical; other lanes are diagnostics.
- Publishable summary history is mirrored for trend ingestion (`bench-results` branch, `history/index.json`).
