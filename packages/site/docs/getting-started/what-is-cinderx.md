# What is CinderX?

According to the upstream README, CinderX is a Python runtime extension package for CPython focused on performance and includes:

- a JIT compiler
- static Python support

The README also notes that CinderX may include extra features not available in stock CPython and that those extras are not guaranteed to be compatible with stock CPython.

Source: [facebookincubator/cinderx README](https://github.com/facebookincubator/cinderx)

## CPython version baseline

The README states CPython 3.14 is the first stock CPython version supported by CinderX.

## Historical context

Meta's October 2023 engineering post describes Cinder hooks being integrated into CPython 3.12 to support future external use and easier maintenance.

Source: [Meta Engineering post](https://engineering.fb.com/2023/10/05/developer-tools/python-312-meta-new-features/)
