# Platform support

From the upstream README:

- Linux x86_64 is the primary supported environment.
- macOS builds are possible, but most features are disabled today.
- Windows is not supported.
- CPython 3.14 is the first supported stock CPython baseline.

Source: [facebookincubator/cinderx README](https://github.com/facebookincubator/cinderx)
