# Overview

This site provides source-grounded documentation for CinderX community users and contributors.

Current scope:

- Practical setup and compatibility guidance
- Benchmark methodology scaffolding
- Community workflows for research and docs quality
- Tutorials, glossary, and FAQ for faster onboarding

## Source Anchors

We currently anchor claims to:

- [CinderX README](https://github.com/facebookincubator/cinderx)
- [Meta Engineering: CPython 3.12 hooks](https://engineering.fb.com/2023/10/05/developer-tools/python-312-meta-new-features/)
- [pyperformance docs](https://pyperformance.readthedocs.io/)

## Why this repo exists

CinderX changes quickly and has platform/version constraints. The goal here is to make those constraints explicit, testable, and easy to follow for external users.
